# iwwwanow / ui-kit

The design language of [owo](https://github.com/iwwwanow/owo) (the engine behind [iwwwanow.ru](https://iwwwanow.ru)) as a drop-in stylesheet, plus a set of AI-generated components built on top of it.

**Preview →** https://iwwwanow.github.io/ui-kit/ · [ai-generated](https://iwwwanow.github.io/ui-kit/ai-generated.html)

## Files

| File | What |
|---|---|
| `owo.css` | owo styles copied 1:1 — generated by `scripts/sync-owo.sh`, never edited by hand. Deviations from owo are collected at the end (source: `scripts/owo-deviations.css`), each linked to a note in owo's backlog |
| `ai-generated.css` | UI components generated by AI from owo conventions, **not hand-crafted**. Needs `owo.css` |
| `index.css` | entry point: imports both |
| `index.html` | owo showcase |
| `ai-generated.html` | ai-generated showcase |

```html
<link rel="stylesheet" href="owo.css">
<link rel="stylesheet" href="ai-generated.css">  <!-- optional -->
```

## owo

Tokens (`--WHITE … --BLACK`, `--RED`, `--BLUE`, `--GRID-GAP*`, `--SEPARATOR-COLUMN`, `--CARD-HEIGHT`), reset, h1–h6 / p / a / pre / code typography, `.wrapper` + `.grid` (`__left-content`, `__right-content`, `--hidden`), `hr` / `.hr_fieldset`, `.border` / `_light` / `_dashed`, `.header` / `.footer`, media card (`.card__wrapper`, `__cover-container`, `__img`, `__text-container`, `__text-header`, `__dir-badge`, `--span-2`, `--span-4`).

Re-sync after owo changes:

```bash
scripts/sync-owo.sh [path-to-owo]   # default: ../iwwwanow_owo
```

## ai-generated

Every class carries the suffix: `btn_ai-generated btn-primary_ai-generated`, `panel__body_ai-generated`.

btn · input · textarea · select · field · checkbox · radio · range · progress · badge · tag · panel · alert · toast · table · tabs · avatar · breadcrumbs · tooltip · spinner · kbd

Conventions borrowed from owo: h4/h5/h6/p type scale only, 1px LIGHT borders → DARK on hover, BLUE for interactive, RED for danger, no radius (except radio and spinner), no transitions, no uppercase.

## Deploy

GitHub Actions (`.github/workflows/pages.yml`) publishes the showcase files on push to `master`.
