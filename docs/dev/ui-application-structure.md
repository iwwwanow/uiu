Левая панель — инструменты (вертикальный тулбар, как в Figma)

Pointer/Select — дефолтный инструмент, выделение существующих элементов. Ты его не называл явно, но без него никак — не может быть только 5 инструментов вставки без инструмента выбора.
Div — вставка блочного контейнера в document flow
Span — вставка инлайн-контейнера
Text — вставка текстового узла
Img — вставка изображения
.html — вставка iframe-обёртки, создаёт новый html-файл, линкует общий styles.css

Левая панель — дерево слоёв. Ты это не просил, но она обязательна, а не опциональна: ты сам определил reorder как "перестановка среди siblings" вместо драга по координатам. Без визуального дерева DOM ты не сможешь понять, где сиблинги, а где нет, и куда именно перетаскиваешь элемент внутри вложенных div'ов. В Figma эту роль играет панель Layers — тебе нужна ровно она, просто отображающая реальный DOM-дерево, а не отдельную модель. Без неё "reorder среди siblings" на практике не будет юзабельным.
Центр — Viewport

Pan (drag пустого места) + zoom (wheel/pinch)
Внутри — Frame: живой DOM открытого файла
Вложенные .html frame — статичные iframe-блоки внутри родительского frame, без своего pan/zoom

Правая панель — три вкладки/секции для выделенного элемента

CSS — raw property-value редактор (как devtools computed/styles), пишет в el.style
Classes — список классов на элементе: чекбоксы существующих + создание нового
Root CSS — read-only браузер всех классов из общего styles.css с их свойствами (для вложенных .html frame показывает тот же общий файл)
