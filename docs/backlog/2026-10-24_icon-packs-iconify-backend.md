# Свои иконочные паки и бэкенд uiu под иконки

**Статус: размытая идея, решений нет.** Всё ниже — направление для обдумывания, ничего не выбрано.

Хочется выложить в uiu свои разные иконочные паки и отдавать клиенту только нужную часть: специальная ссылка со списком иконок, а бэкенд возвращает подборку. Похоже, это уже решено готовым инструментом. Iconify API отдаёт подборку по URL (`/<pack>.css?icons=a,b`, `/<pack>.json?icons=…`, `/<pack>/<icon>.svg`), поднимается у себя в Docker (`iconify/api`) и умеет подключать собственные наборы в формате Iconify JSON. Значит, у uiu появится бэкенд — пока только под иконки, дальше, возможно, шире.

Открытые вопросы на потом: в каком формате хранить паки в репо (Iconify JSON, сырые SVG + конвертация); свой Iconify API или свой сервис; где он живёт (рядом с owo, отдельно); нужна ли параллельно выдача без сервера — сборка спрайта или CSS из списка иконок на этапе сборки; как это сочетается со статикой на Pages.
