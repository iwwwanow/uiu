# Варианты нового названия для репозитория ui-kit

`ui-kit` — единственное чисто описательное имя среди проектов (`owo`, `xtc-toaster`, `rubka`, `kanalveschaniya`), и оно уже не отражает суть: в репо теперь и CSS-кит, и визуальный редактор html-файлов. Кандидаты в стиле остальных:

- **`verstka`** (вёрстка) — фаворит: буквально то, чем занимается проект, рифмуется с `rubka`.
- **`lekalo`** (лекало) — запасной: шаблон, по которому кроят; кит задаёт форму, редактор — раскрой.
- `trafaret` (трафарет) — хорошо про кит, хуже про редактор.
- `kalka` (калька) — редактирование поверх реальных файлов, но менее очевидно.
- `uwu` — шуточная отсылка к `owo`, откуда взят дизайн-язык.
- Если всё-таки скучно-описательное: `html-studio`, `kit-editor`.

При переименовании поменяется: URL GitHub Pages (`iwwwanow.github.io/ui-kit/`), `name` в `package.json`, README и og-мета, локальная папка `iwwwanow_ui-kit` (и привязанная к пути память Claude).
